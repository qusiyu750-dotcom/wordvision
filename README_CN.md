# WordVision 图片背词个人版

这是一个可在手机浏览器中使用、并可部署为 PWA（渐进式网页应用）的个人英语词汇学习项目。

## 已实现功能
- 图片学习：查看图片、英文单词、例句，再显示中文释义。
- 看图猜词：根据图片从选项中选择单词，并显示答题反馈。
- 图片 + 语义联想：先看图回忆单词，再查看答案。
- 自建词库：添加、编辑、删除单词；为单词手动上传图片。
- CSV / TXT 导入；导出 CSV；导出包含图片与学习记录的完整 JSON 备份；从 JSON 备份恢复。
- 本地保存：使用浏览器 IndexedDB 保存词表、图片和学习记录。
- PWA 基础支持：部署到 HTTPS 网站后，可添加到手机主屏幕，并缓存主要页面资源。

## 最简单的使用方式
1. 解压项目压缩包。
2. 先在电脑上用代码编辑器打开文件，或把整个文件夹部署到一个静态网站托管服务。
3. **不要只把 `index.html` 当作普通文件双击打开来判断安装功能**。IndexedDB 在部分本地文件环境中可能工作，但 PWA 安装与离线缓存需要通过 localhost 或 HTTPS 访问。
4. 添加几个单词并上传图片；或者在“我的词库”中导入 CSV。
5. 建议定期点击“导出完整备份（含图片）”，以防浏览器数据被清理。

## CSV 格式
第一行推荐使用标题：
`word,meaning,pos,example`

例如：
`bridge,桥；桥梁,noun,A bridge connects two sides of a river.`

TXT 格式每行一个词，字段可以用 Tab 或竖线 `|` 分隔：
`bridge|桥；桥梁|noun|A bridge connects two sides of a river.`

图片不从 CSV 自动导入，需要在应用中手动上传。

## 如何部署并添加到 iPhone 主屏幕
1. 将本文件夹内的全部文件上传到支持静态网站的 HTTPS 托管服务。
2. 打开部署后的网站，确认页面正常加载。
3. 在 iPhone 上使用 Safari 打开网站。
4. 点击分享按钮，选择“添加到主屏幕”。
5. 从主屏幕打开后即可像轻量应用一样使用。

## 数据与隐私说明
- 本版本没有账号系统，也不会自动把单词或图片上传到云端。
- 数据保存在当前浏览器的本地数据库中。清理浏览器网站数据、换设备或换浏览器可能导致数据无法访问。
- 完整备份文件包含你自己的词表和图片，可能含有个人资料，请妥善保管。
- 此版本是个人使用原型，不等同于已经上架 App Store 的原生 iOS 应用。

## 重要提示
- 当前代码已实现基础功能，但不同浏览器的 PWA 安装入口可能不同。
- 为了保护数据，建议定期备份。
- 如果后续需要多设备同步、账号登录、词书共享或 App Store 上架，需要增加后端或开发原生应用。
